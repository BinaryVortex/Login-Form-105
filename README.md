# Login Form

Login Form Built Using HTML, CSS and JavaScript.

A clean, responsive login form template suitable for small projects, demos, or learning purposes.

## Screenshot

![Login Form Screenshot](./Screenshot%202024-08-09%20202549.png)

## Demo / Preview

To view the form locally:

- Clone the repository:

  git clone https://github.com/BinaryVortex/Login-Form-105.git
- Open `index.html` in your browser, or serve the folder with a simple HTTP server (recommended):

  - Python 3: `python -m http.server 8000` then open `http://localhost:8000`

## Features

- Clean, minimal design using HTML & CSS
- Basic client-side interaction with JavaScript
- Ready to be integrated into larger projects or backend authentication flows
- Responsive layout that works well on desktop and mobile

## Files

- `index.html` — markup for the login form
- `style.css` — styling and responsive rules
- `Screenshot 2024-08-09 202549.png` — screenshot used above
- `digital-lavender-natural-landscape.jpg` — background/sample image included in the repo

## How to Customize

- Edit `index.html` to change labels, placeholders, and form action.
- Modify `style.css` to adapt colors, spacing, or fonts.
- Replace the background image file to change the look and feel.

## Notes

This project is intended as a static front-end template. For production use, connect the form to a secure server-side authentication system and validate all inputs on the server.
